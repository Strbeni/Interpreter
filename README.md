A custom interpreter built using Java, designed to parse, evaluate, and execute a simple programming language named Quetzal.
This project focuses on understanding language design, parsing, AST evaluation, and execution flow.

### 📌 Features (Till Now)

1.Lexical analysis (tokenization)

2.Syntax parsing

3.Error handling with meaningful messages
